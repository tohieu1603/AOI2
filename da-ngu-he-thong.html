3Hai lớp dịch thuật (Two-Layer Translation)

📋 Layer 1 — UI Control Translation

Bảng: tblanguage

  • Dịch các control cố định: Label, Button, MenuItem
  • Key = classname + controlname
  • Load 1 lần lúc khởi động form
  • Framework tự động áp vào control
Ví dụ:
Form_Main | toolStripMenuItem_Calib
🇨🇳 标定 → 🇻🇳 Hiệu chuẩn
Form_Main | toolStripMenuItem_Produce
🇨🇳 生产 → 🇻🇳 Sản xuất

💬 Layer 2 — Runtime Text Translation

Bảng: textTranslation

  • Dịch chuỗi động trong code lúc runtime
  • Key = chuỗi Hán văn gốc
  • Gọi thông qua .txtTrans(TransType.Trans)
  • Tổng: 4.327 bản ghi dịch thuật
Ví dụ:
🇨🇳 "加载参数"
→ 🇬🇧 "Load parameters"
→ 🇻🇳 "Tải tham số"

5Luồng đổi ngôn ngữ lúc runtime
① User click chọn ngôn ngữ trên UI

Có thể là button hoặc menu item ngôn ngữ trên Form_Main (nằm trong AF.Data.Language.dll — không thấy source)

② LanguageMgr.Instance lưu ngôn ngữ mới

Cập nhật currentLan trong tbSysParam → SQLite ghi vào language.db

③ LanguageMgr bắn event eventChangeLanguage

Tất cả subscriber đã đăng ký sẽ nhận được thông báo

④ Form_Main.OnChangeLanguage() — cập nhật ToolStrip, MenuItem

Lặp qua các ToolStripMenuItem và cập nhật Text từ .txtTrans(TransType.Trans)

⑤ Form_Auto.OnChangeLanguage() — cập nhật DataGrid + logGroup

Cập nhật HeaderText của các column trong dataGridViewProductDataShow

⑥ Layer 1 (tblanguage) tự động apply cho control tĩnh

Framework trong DLL tự scan form và update text cho Label, Button, v.v.

📝 Code đăng ký event trong dự án

// Form_Auto.cs — dòng 254
LanguageMgr.Instance.eventChangeLanguage += OnChangeLanguage;

// Form_Main.cs — dòng 342
LanguageMgr.Instance.eventChangeLanguage += OnChangeLanguage;
LanguageMgr.Instance.eventChangeLanguage += () =>
{
    tssl.Text = tssl.Tag.ToString().txtTrans(TransType.Trans);
};
OnChangeLanguage();  // Gọi ngay 1 lần lúc load form

7Phân bố sử dụng trong dự án

📂 Files dùng TransType.Trans (dịch UI)

  • Form_Main.cs — ~20 chỗ
  • Form_Auto.cs — cột DataGrid, header
  • Form_Auto_CustomPanel.cs — MessageBox
  • Form_UnloadInfo.cs — MessageBox

📂 Files dùng TransType.Mark (log/event)

  • TcpCommu_Camera.cs — lỗi kết nối
  • TcpCommu_Camera_CCD1.cs — lỗi param
  • TcpCommu_Robot.cs — lỗi param
  • TcpCommu_Camera_AOI.cs — timeout
💡 Điểm khác biệt Trans vs Mark:
TransType.Trans → dịch và hiển thị ra UI cho user thấy
TransType.Mark → ghi vào log/event system (có thể dùng để tra cứu sau, không nhất thiết phải đẹp)
